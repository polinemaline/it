# Интернет будущего — мультимедийный лонгрид

Лабораторная работа №2 по дисциплине «Интернет-технологии».
Автор: Гостенкова Полина Юрьевна, ИДМ-26-01, МГТУ «СТАНКИН», 2026.

Содержание подготовлено на основе реферата лабораторной работы №1 «Основные направления развития современных Интернет-технологий» с дополнительными проверяемыми исследованиями и практическими примерами. Тема: Web 3.0, NFT, технологии удалённой работы и цифровые рабочие пространства.

## Что включено

- `index.html`: заголовок, кликабельное содержание с якорями, семь глав, выводы и библиография.
- `styles.css`: адаптивная верстка, анимации, типографика, поддержка уменьшения анимации.
- `script.js`: прогресс чтения, мобильное меню, переключение типов токенов, интерактивная схема жизненного цикла NFT, тест с обратной связью и кнопка наверх.
- `assets/hero-network.svg`, `assets/token-journey.svg`: оригинальные графические иллюстрации.
- `assets/intro.mp3`: аудиоверсия краткого вступления на русском языке, синтезированная речь.
- Фото (Wikimedia Commons, CC BY 2.0), встроенный YouTube-ролик GitLab и внешние ссылки на исследования. Фото и видео требуют подключения к интернету; видеоплеер также зависит от возможности встраивания YouTube в стране и браузере читателя.

## Как посмотреть локально

Откройте `index.html` двойным щелчком или запустите локальный сервер, если хотите:

```bash
python -m http.server 8000
```

После этого откройте `http://localhost:8000`.

## Публикация на GitHub Pages через интерфейс

1. Войдите в [GitHub](https://github.com/) и нажмите **+ → New repository**.
2. Назовите репозиторий, например `internet-future-longread`. Для GitHub Free выберите **Public**. Нажмите **Create repository**.
3. Распакуйте архив проекта. **Загружайте содержимое папки**, а не саму внешнюю папку: `index.html`, `styles.css`, `script.js`, каталог `assets/`, `.nojekyll` и `README.md` должны лежать в корне репозитория.
4. В репозитории выберите **Add file → Upload files**. Выделите файлы и папку `assets` и перетащите на страницу. Если браузер не перенёс скрытый `.nojekyll`, он для этого проекта не обязателен. Нажмите **Commit changes**.
5. Откройте **Settings → Pages**. В разделе **Build and deployment** установите **Source: Deploy from a branch**.
6. В **Branch** выберите `main` и `/(root)`, нажмите **Save**.
7. После завершения развёртывания в **Settings → Pages** появится **Visit site**. Адрес будет вида `https://ВАШ-ЛОГИН.github.io/internet-future-longread/`.
8. Откройте опубликованный адрес и проверьте оглавление, переключатели NFT, тест, аудио, внешние ссылки и видео. Отправьте преподавателю **адрес сайта**, а не ссылку на репозиторий.

**Важно:** GitHub Pages — публичная публикация. Не добавляйте в репозиторий личные данные, которые не хотите раскрывать.

## Альтернативный вариант через Git

```bash
git init
git add .
git commit -m "Add multimedia longread"
git branch -M main
git remote add origin https://github.com/USERNAME/internet-future-longread.git
git push -u origin main
```

Создайте пустой репозиторий заранее и замените `USERNAME` на свой логин. Затем включите Pages, как описано выше.
