# Интернет будущего

Минималистичный адаптивный лонгрид о Web 3.0, NFT, токенизации и удалённой работе.

## Содержимое проекта

- `index.html` — основной материал, навигация по разделам, ссылки на исследования и практические примеры.
- `styles.css` — оформление страницы для компьютера и телефона.
- `script.js` — индикатор чтения, мобильное меню, интерактивные схемы и мини-тест.
- `assets/token-journey.svg` — поясняющая схема NFT.
- `assets/intro.mp3` — короткая аудиоверсия вступления.

Сайт не требует сборки, фреймворков и сторонних библиотек. Аудио и схема хранятся локально, внешние ссылки ведут на первоисточники.

## Открыть на компьютере

Дважды нажмите на файл `index.html`. При необходимости можно запустить локальный сервер:

```bash
python -m http.server 8000
```

После запуска откройте `http://localhost:8000`.

## Размещение на GitHub Pages

1. Создайте публичный репозиторий GitHub, например `internet-future-longread`.
2. Загрузите **содержимое** папки (файл `index.html` должен находиться в корне репозитория, а не во вложенной папке).
3. Сохраните изменения (**Commit changes**).
4. Откройте **Settings → Pages → Build and deployment**.
5. Выберите **Deploy from a branch**, ветку **main**, папку **/(root)** и нажмите **Save**.
6. Дождитесь публикации и откройте адрес вида `https://USERNAME.github.io/internet-future-longread/`.

При обновлении существующего сайта можно заменить файлы в том же репозитории. GitHub Pages автоматически опубликует новую версию.

## Функциональность

- оглавление с переходами к разделам;
- переключение двух типов токенов;
- четыре этапа жизненного цикла NFT;
- исследовательские материалы и ссылки на публикации;
- мини-тест с обратной связью;
- аудио и адаптивная верстка.

При публикации в открытом репозитории содержимое сайта будет доступно всем пользователям интернета.
