# Современные интернет-технологии

Статический мультимедийный лонгрид о Web 3.0, NFT, инфраструктуре удалённой работы и информационной безопасности. Дизайн — минималистичный, без фреймворков, сборщиков и внешних медиазависимостей.

## Содержание

- `index.html` — статья, кликабельное оглавление, интерактивные блоки и выводы.
- `styles.css` — адаптивная типографика, оформление медиа и анимация исследовательского графика.
- `script.js` — мобильная навигация, интерактивное сравнение токенов, этапы жизненного цикла NFT, проверочный вопрос, анимация графика.
- `assets/remote-workspace.webp` — иллюстративное фотореалистичное изображение рабочего места.
- `assets/token-journey.svg` — схема связей токена и метаданных.
- `assets/zero-trust-process.mp4` — 24-секундный ролик о проверке удалённого доступа.
- `assets/zero-trust-ru.vtt` — субтитры видеоролика.
- `assets/zero-trust-poster.webp` — кадр-заставка для видео.
- `assets/nft-explainer.mp3` — краткий звуковой разбор устройства NFT.
- `assets/nft-audio-transcript.txt` — текст аудиоматериала.
- `.nojekyll` — совместимость с GitHub Pages.

Фото/иллюстрация, схема, диаграмма, анимация, видео и аудио размещены в тематических разделах и содержательно раскрывают материал.

## Публикация на GitHub Pages

1. Создайте общедоступный репозиторий в GitHub.
2. Добавьте **содержимое** этой папки в корень репозитория: `index.html`, `styles.css`, `script.js`, `.nojekyll` и папку `assets/`. Не помещайте их в дополнительную вложенную папку.
3. Выполните commit.
4. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**.
5. Выберите ветку `main`, каталог `/(root)` и сохраните настройки.
6. После публикации откройте ссылку `https://ВАШ_ЛОГИН.github.io/ИМЯ_РЕПОЗИТОРИЯ/`.

При замене предыдущей версии удалите старые неиспользуемые медиафайлы из репозитория, чтобы они не остались в публикации.

## Проверка

Откройте `index.html` в современном браузере. Кликабельные пункты содержания должны вести к соответствующим разделам. Включите ролик и аудиофрагмент, проверьте интерактивное сравнение токенов и переключение этапов NFT. Весь сайт работает без сервера и без npm.
