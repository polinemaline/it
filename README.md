# Современные интернет-технологии

Одностраничный адаптивный информационный сайт о Web 3.0, NFT, токенизации и технологической инфраструктуре удалённой работы.

## Файлы проекта

- `index.html` — основной текст, навигация и ссылки на исследования и практические материалы.
- `styles.css` — минималистичное оформление, адаптивное к разным размерам экрана.
- `script.js` — интерактивное сравнение типов токенов, этапы жизненного цикла NFT, проверочный вопрос, мобильная навигация и индикатор чтения.
- `assets/token-journey.svg` — поясняющая техническая схема.
- `.nojekyll` — служебный файл для GitHub Pages.

Сайт не использует сторонние JavaScript-библиотеки и не требует сборки. Все основные файлы находятся локально.

## Запуск

Откройте `index.html` в браузере. При необходимости используйте локальный сервер:

```bash
python -m http.server 8000
```

Затем откройте `http://localhost:8000`.

## Публикация на GitHub Pages

1. Создайте репозиторий в GitHub или откройте ранее созданный.
2. Загрузите в корень репозитория содержимое проекта, включая `index.html`, `styles.css`, `script.js` и папку `assets`.
3. Удалите старые аудиофайлы (`assets/intro.mp3` и `assets/intro-text.txt`), если они остались в репозитории после предыдущей версии.
4. Сохраните изменения (**Commit changes**).
5. Откройте **Settings → Pages** и выберите **Deploy from a branch**, ветку **main**, папку **/(root)**.
6. После публикации проверьте страницу по адресу `https://USERNAME.github.io/REPOSITORY/`.

В проекте сохранены навигация по якорям, интерактивные блоки, схема, ссылки на исследования и практические кейсы. Видео и аудиовоспроизведение не используются.
