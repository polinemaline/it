# Современные интернет-технологии — лонгрид

Готовый статический сайт для GitHub Pages.

## Публикация
1. Загрузите файлы `index.html`, `styles.css`, `script.js`, `.nojekyll` из корня архива в корень публичного репозитория GitHub.
2. В Settings → Pages выберите Deploy from a branch → main → / (root).
3. Откройте опубликованную ссылку.
